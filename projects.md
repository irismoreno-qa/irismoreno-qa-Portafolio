**Estado:** ✅ Completado

**Framework:** Playwright  
**Fecha:** Agosto 2026

---

### 📝 Descripción del Proyecto

Sistema de registro de inscripción a la Academia sin humo. Este proyecto final del curso **Ruta de Transformación** demuestra mis competencias integrales en:

- **Análisis de requerimientos** y diseño de estrategia de testing
- **Testing manual exhaustivo** de flujos críticos
- **Automatización de pruebas** con Playwright
- **Documentación profesional** de casos de prueba y defectos
- **Integración** de manual + automatización

---

### 🎯 Objetivos del Proyecto

✅ Validar todos los flujos de inscripción  
✅ Identificar y documentar defectos críticos  
✅ Garantizar la calidad del sistema de registro  
✅ Aplicar mejores prácticas de QA  
✅ Crear suite de automatización reutilizable  

---

#### Áreas Probadas
```

✅ Campos obligatorios y opcionales

✅ Mensajes de error y confirmación

```


### 🚀 Cómo Usar Este Proyecto

**Clonar el repositorio:**
```bash
git clone https://github.com/irismoreno-qa/academia-sin-humo-qa-proyecto-final.git
cd academia-sin-humo-qa-proyecto-final
```

**Instalar dependencias:**
```bash
npm install
```

**Ejecutar tests automatizados:**
```bash
npm test
```

**Ejecutar tests en modo UI (Playwright):**
```bash
npx playwright test --ui
```
